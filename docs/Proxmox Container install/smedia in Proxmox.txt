smedia auf Proxmox:

Container-login:
root / devau


LXC-Container einrichten (debian 12 bookworm)
1. Im LXC-Container ausführen:
apt update
apt install -y ca-certificates curl gnupg git
install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/debian/gpg -o /etc/apt/keyrings/docker.asc
chmod a+r /etc/apt/keyrings/docker.asc

2. Docker-Repository eintragen:
tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/debian
Suites: $(. /etc/os-release && echo "$VERSION_CODENAME")
Components: stable
Architectures: $(dpkg --print-architecture)
Signed-By: /etc/apt/keyrings/docker.asc
EOF

3. Docker install
apt update
apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

4. Docker testen
docker --version
docker compose version
docker run hello-world

---------------------------------------
5. Projekt auf den LXC holen
mkdir -p /opt/apps
cd /opt/apps
git clone https://github.com/jwae/smedia
cd smedia

cp .env.docker .env
nano .env   (passwörter merken / ändern)

-----.env Original -----------
NODE_ENV=production
API_PORT=3001
FRONTEND_PORT=8080

DB_HOST=mariadb
DB_PORT=3306
DB_NAME=smedia
DB_USER=smedia_app
DB_PASSWORD=change-me
DB_ROOT_PASSWORD=change-root-password
DB_CONNECTION_LIMIT=10

MARIADB_PORT=3308
------------------------

6. Starten
docker compose up -d --build
docker compose ps

Logs prüfen: docker compose logs -f
Die IP des LXC: hostname -I
Frontend: http://IP:8080
